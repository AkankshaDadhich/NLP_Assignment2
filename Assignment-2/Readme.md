# Chunk Tagger 

This Python script is used to create Chunk Tags for the corresponding POS Tags. 
 

## How to Run 

Navigate to the directory where Assignment-2 is located.

To Run the script "python Assignment-2/chunk_tagger.py"

To check the demo, run "streamlit run Assignment-2/web_demo.py"

Input to streamlit is the correspondinf POS Tag (eg. 2314)


## Example

$ python Assignment-2/chunk_tagger.py

$ streamlit run Assignment-2/web_demo.py
